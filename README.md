# ExoTic-Fish-Exoskeleton

Executive Summary 

This project aims to design, develop, and validate a lightweight, waterproof, and non-invasive exoskeleton for live, free-swimming fish to study aquatic movement in varying environments. Traditional camera-based systems are insufficient for capturing long-duration [Hussain, 2024 and Hamann 2024], detailed behaviors in such conditions, limiting the understanding of aquatic life and its potential for bio-inspired innovation. Team ExoTic’s proposed solution will address these challenges by enabling real-time curvature measurement, data storage, and posture-based visual feedback using RGB LEDs.  

Design Problem and Motivation 

Understanding aquatic behavior in natural habitats is essential for advancing marine biology, conservation, and bio-inspired design. Current tools such as video surveillance fail to capture fish movements in nocturnal, deep-sea, or high-turbidity conditions [McConnell, 2013]. This gap hampers scientific understanding and innovation. By developing a non-invasive exoskeleton, researchers can gain unprecedented insights into fish behavior, even in challenging environments. 

Technical Problems 

The project presents several challenges, including: 

Designing a lightweight and flexible exoskeleton that fits securely without restricting movement. 

Ensuring waterproofing to function effectively underwater. 

Incorporating curvature sensors capable of capturing precise data in real time. 

Converting curvature data into PWM signals to control RGB LED output, representing fish posture visually. 

Developing an expandable system that allows the addition of future sensors. 

Objective and Approach 

The objective is to create a durable, minimally invasive exoskeleton that integrates hardware and software for real-time data acquisition and visualization. The approach involves: 

Using CAD tools and 3D printing to prototype an exoskeleton tailored to the fish's body. 

Selecting lightweight, waterproof materials to ensure durability and natural swimming behavior. 

Implementing sensors and microcontrollers to process curvature data, convert it into PWM signals, and control RGB LEDs. 

Validating the design through testing in The Whitney Lab for Marine Bioscience at the University of Florida. 

Tools and Methods 

CAD Software: For precise design and fit. 

3D Printing: To prototype the exoskeleton using flexible, waterproof materials. 

Curvature Sensors and Microcontrollers: To capture and process real-time data. 

Software Development: For data acquisition, processing, and signal conversion.
